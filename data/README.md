# Data

The dataset was provided by the module team for the coursework and is not redistributed here.

It contains 23,171 airline reviews from AirlineQuality.com (Skytrax): 20 columns covering airline, overall rating (1–9), six service ratings (1–5), traveller type, seat type, route, verification status, free-text review and a yes/no **Recommended** label. It matches the public Kaggle dataset [Airline Reviews (Juhi Bhojani)](https://www.kaggle.com/datasets/juhibhojani/airline-reviews), which has the same size and columns.

To re-run the notebook, download the file, save it as `airline_reviews.csv`, and update `file_path` in the data-loading cell. The notebook was written for Google Colab and reads from Google Drive.
